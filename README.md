# Gestión de Trabajos Agrícolas (Java Web - JEE)

Este proyecto es una aplicación web desarrollada en Java Web (JEE) como parte de un ejercicio práctico para el aprendizaje y aplicación del patrón Modelo-Vista-Controlador (MVC), Servlets, JSP, DAOs y modelos de datos. Se trata de una adaptación del proyecto original en PHP, manteniendo la misma funcionalidad de gestión integral de trabajos agrícolas en parcelas pertenecientes a agricultores de diferentes Comunidades Autónomas (CCAA).

## Objetivos de Aprendizaje

* **Aplicación del Patrón MVC:** Comprender y aplicar el patrón Modelo-Vista-Controlador en un proyecto web real.
* **Desarrollo con Java EE:** Aprender a utilizar Servlets y JSP para la construcción de aplicaciones web dinámicas en Java.
* **Acceso a Datos con DAOs:** Implementar el patrón Data Access Object (DAO) para la gestión de la persistencia de datos.
* **Modelado de Datos:** Diseñar y utilizar modelos de datos para representar las entidades del dominio (Agricultores, Maquinistas, Trabajos, etc.).
* **Migración de Aplicaciones:** Adquirir experiencia en la migración de funcionalidades entre diferentes plataformas (PHP a Java).

## Funcionalidad del Proyecto

La aplicación mantiene la funcionalidad del proyecto original en PHP:

* **Gestión de Usuarios:** Roles de Agricultor, Maquinista y Administrador con diferentes niveles de acceso.
* **Gestión de Parcelas y Máquinas:** Administración de recursos agrícolas.
* **Gestión de Trabajos:** Creación, asignación y seguimiento de trabajos agrícolas.
* **Facturación:** Generación y gestión de facturas basadas en los servicios prestados.
* **Interfaz de Usuario:** Páginas JSP para la presentación de la información y Servlets para el control de la aplicación.

## Tecnologías Utilizadas

* **Java EE:** Desarrollo del backend utilizando Servlets y JSP.
* **Modelo-Vista-Controlador (MVC):** Patrón de diseño para la arquitectura de la aplicación.
* **DAO (Data Access Objects):** Patrón de diseño para la gestión de la persistencia de datos.
* **MySQL:** Sistema de gestión de bases de datos para el almacenamiento de datos.
* **JSP (JavaServer Pages):** Para la creación de la interfaz de usuario.
* **HTML, CSS, JavaScript:** Tecnologías del lado del cliente para la mejora de la interfaz de usuario.
* **Servlets:** Controladores de la aplicación.

## Instalación

1.  Clona el repositorio: `git clone <URL del repositorio>`
2.  Configura la base de datos MySQL.
3.  Despliega la aplicación en un servidor de aplicaciones Java EE (e.g., Tomcat, GlassFish).
4.  Configura las conexiones a la base de datos en el archivo de configuración correspondiente.
5.  Accede a la aplicación a través del navegador web.
